서비스 소개

안전한 환경에서 정복하는 ui/ux 훈련

수업을 들으며 실습을 따라하고 오류가 발생하면 오류를 해결 할 수 있다.

훈련 방법

  • 실습진행

    수업에 따라 실습 진행 한다

  • 복습진행

    수업이 끝난 후 복습을 진행한다

  • git 훈련

    처음 써보는 git을 이해한다

훈련 순서

  1. vscode를 설치합니다.
  2. git을 설치합니다
  3. git 회원가입 후 로그인 합니다.
  4. 실습 진행을 합니다.
  5. 진행한 실습을 git에 올린다

훈련 소식을 메일로 받아보세요!!
