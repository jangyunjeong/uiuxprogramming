## 나의 UIUX 훈련

## 사용자의 목표
 - 사용자 : UIUX를 공부하는 사람 (나)
 - 목표 : 훈련 조건을 정하고, 조건대로 진행해본다

 ## 조건
 1. 화면에서 문자/이메일 설정 할 수 있도록 만들었습니다. 화면에서 문자/이메일 영역이 안보입니다.
 2. 수신동의여부 체크박스를 클릭 시 문자 또는 이메일을 설정할 수 있도록 dialog 버튼을 만들었습니다.
 3. '이메일로 받기' 클릭 하면 전에 만들었던 이메일로 소식 받기 영역이 생성이 되면서 이메일 체크를 할 수 있습니다.
 4. '문자로 받기' 클릭 하면 문자를 받을 번호를 입력하고, 확인 버튼을 누르면 입력한 번호를 확인할 수 있습니다.
 5. 수정하기 버튼을 클릭하면 다시 입력폼이 있는 곳으로 이동을 하고 설정 완료하기 버튼을 클릭하면 완료된 문구를 확인 할 수 있습니다.
 6. 동의하기 체크박스가 체크 해제가 되면 문자와 이메일 영역이 사라지면서 체크를 해서 선택을 해야지만 보일 수 있게 했습니다.
