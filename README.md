## 나의 UIUX 훈련

## 추가된 기능
 - 이전에 훈련소식을 메알로 받는 작업을 진행했습니다. 그 메일을 받고 훈련을 신청하는 폼을 만들어보았습니다.
 

## 사용자의 행동
 1. 폼에 이름, 핸드폰번호, 훈련일자, 난이도 선택이 보입니다.
   - 이름, 핸드폰번호, 훈련일자에 값을 넣지 않고 입력내용확인 버튼을 클릭 시 하단에 error문구 노출
   - 이름 3글자, 핸드폰번호와 훈련일자를 형식에 맞게 넣지 않으면 입력조건 체크 error 문구 노출
   - 난이도 선택은 필수값이 아님
   - 오류 시 focus 처리 하여 값을 바로 입력하도록 처리
   - 오류 시 input 선에 빨간색을 노출시켜 사용자가 잘못 입력한 내용이 눈으로 보임

2. 입력내용확인 버튼 클릭 수 사용자가 입력한 값들이 눈으로 확인 가능
   - 굵은 글씨로 사용자가 입력한 값을 표현
   - 전단계에서 난이도 체크박스 선택을 하지않고 입력 시 난이도 없음으로 노출, 난이도 체크박스를 선택 후 난이도 선택 시 선택한 난이도값이 화면에 노출됩니다.
   - '수정하기' 버튼을 클릭 시 전 단계에서 입력한 폼 내용이 보입니다. 수정이 가능합니다.
   - '계획저장하기' 버튼 클릭 시 ' 입력한 계획을 저장하고있습니다.' 문구 확인 가능 
      submit 버튼을 이용해 제출하는 형식으로 보이고, 중복으로 되지 않도록 처리했습니다.

3. 신청완료 화면이 노출
   - '새 훈련 신청하기' 버튼 클릭 시 첫번쨰 입력폼으로 이동
   - form에 있는 모든 내용을 초기화 했습니다.

4. 모바일 테스트
   - 모바일도 pc와 방법은 동일하게 진행합니다.
   - 모바일에서는 버튼과 라디오버튼, input 텍스트가 잘리지 않는지 확인했고 
     어색한 부분이 없도록 처리해보았습니다.
