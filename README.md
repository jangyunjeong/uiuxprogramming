## 5주차 사용자 향동에 반응하는 웹페이지

## 확인할 문제 
하단에 이메일 폼에 신청하기 버튼을 클릭 했을때의 변경상

## 수정한 내용
 - 폼에 버튼 동작에 필요한 스크립트를 사용했다
 - 입력폼에 입력값이 없는 상태에서 버튼 클릭 시 화면이 넘어가지않고 하단에 문구가 변경되면서 입력폼에 포커스를 생성했다
 - 입력폼에 정상적은 이메일 형식을 넣었을 경우 버튼은 더이상 클릭 될수없게 처리를 했다.
 - 하단에는 입력한 이메일을 문구에 추가하여 넣었다 

 ## 확인할 내용
 1. 이메일 폼에 아무것도 넣지않고 신청버튼을 클릭하면 화면이 넘어가지않고 입력폼에 포커스가 생긴다
 2. 이메일 폼에 정상적으로 이메일 형식을 넣고 버튼을 클릭하면 버튼 색이 변하면서 더이상 클릭할수없게 되고 하단에 신청한 이메일 주소와 문구가 뜹니다.
