## 나의 UIUX 훈련

## 추가된 기능
 - 다른 사람들이 기획한 사이트로 들어와서 화면을 보고 피드백을 남기도록 기능을 추가
 - 작성을 하면 기획자가 이메일로 피드백 내용을 받을 수 있도록 기획

## 사용자의 행동
 1. 화면에 있는 피드백 영역에 닉네임, 기능평가, 피드백 내용을 입력
  - 셋중에 하나라도 값이 없으면 error문구로 사용자에게 알려주고, focus로 이동
 2. 입력 폼에 내용을 모두 입력 후 저장 버튼을 클릭
  - 클릭 시 입력폼에 내용이 없으면 error 문구가 띄워짐
  - 클릭 시 입력폼에 내용이 다 들어가 있으면 팝업이 띄워짐
 3. 입력폼에 입력한 내용이 dialog 팝업에 정상적으로 보임
  - 하단 버튼에 이메일로 보내기 클릭 시 이메일 성공 팝업이 띄워짐
  - 하단 버튼에 수정하기 틀릭 시 해당 팝업이 닫아지고, 직전에 작성했던 내용들이 남아있다. 
 4. 이메일로 보내기 버튼 클릭 시 이메일 전송 완료 되었다는 팝업이 띄워짐
  - 닫기 버튼을 클릭 하면 해당 팝업이 닫아지고, 입력폼에 있는 값들이 전부 초기화 됨
